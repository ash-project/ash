# Ash.DataLayer.Ets

An ETS (Erlang Term Storage) backed Ash Datalayer, for testing and lightweight usage.

Remember, this has no support for transactions unless the resource sets `transactions? true`
in its `ets` section, and then only for a table that is not `private?`. This is not
recommended for production use, especially in multi-user applications. It can, however, be
great for prototyping.


## ets
A section for configuring the ets data layer




### Examples
```
ets do
  # Used in testing
  private? true
end

```




### Options

| Name | Type | Default | Docs |
|------|------|---------|------|
| [`private?`](#ets-private?){: #ets-private? } | `boolean` | `false` | Sets the ets table protection to private, and scopes it to only this process. The table name will not be used directly if this is true, to allow multiple processes to use this resource separately. |
| [`transactions?`](#ets-transactions?){: #ets-transactions? } | `boolean` | `false` | Runs the resource's actions in transactions. A transaction holds a lock on each table it touches, and a rollback puts back what it changed. A `private?` table, held by one process, has no transactions. |
| [`table`](#ets-table){: #ets-table } | `atom` |  | The name of the table. Defaults to the resource name. |
